# ToolsDev

Depending on the density of the model, you might have to experiment with the decimation and retopology.

When you load in the model, you will first decimate the model, after that click apply(continue editing), and that will switch you to the retopologising, aftwer which you can pick and try with the preview and see what you like, before accepting.

Good setting for the face.fbx test model, is decimation down to ~80k vertices, apply and continue, before going down with retopology to ~1500 - 1800 vertices. If you see holes in the retopologised model, either bring the vertices down, or try clicking preview button again, as it will recalculate the mesh.
